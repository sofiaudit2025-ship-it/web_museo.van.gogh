# Van Gogh Museum Web

Sitio web dedicado al Van Gogh Museum Amsterdam elaborado por Sofía Iglesias, Emma Lago, Sofía Lajarín y Robert Rodriguez, como proyecto final de Diseño web avanzado. 

## Contenido principal

- Inicio con biografía, firma animada y acceso al resto de contenido de la web.
- Seccion de información relevante sobre el museo y compra de entradas.
- Galeria de obras con API.
- Tienda y compra de artículos.
